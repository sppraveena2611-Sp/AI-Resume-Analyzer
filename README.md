# AI Resume Analyzer 🤖📄

A web-based AI Resume Analyzer developed using Python and Flask. The application analyzes a user's resume based on a given job description and identifies matching and missing skills.

## Features

- Resume text analysis
- Job description analysis
- Skill matching
- Missing skill detection
- Resume match percentage calculation
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How It Works

1. Enter or paste your resume details.
2. Enter the job description.
3. Click the **Analyze Resume** button.
4. The application compares the skills in both inputs.
5. View the matched skills, missing skills, and resume match score.

## How to Run the Project

### Install Flask

pip install flask

### Run the Application

python app.py
